# Soul-agent 开发文档

| 文档 | 内容 |
|------|------|
| [开发设计方案](开发设计方案.md) | 项目定位、技术选型、目录结构、核心模块设计、数据库设计、开发计划 |
| [系统架构](系统架构.md) | 分层架构、模块职责、类关系、数据流转、启动流程、设计决策 |

## 阅读建议

- **了解全貌**：先读 [开发设计方案](开发设计方案.md) 和 [系统架构](系统架构.md)。
- **理解运行链路**：读 [应用入口模块](模块文档/应用入口模块.md) 和 [核心模块](模块文档/核心模块.md)。
- **深入具体模块**：按需阅读 `模块文档/` 中的模块文档。
- **查接口细节**：读 [API参考](API参考.md)。
