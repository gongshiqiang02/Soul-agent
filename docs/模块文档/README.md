# 模块文档

本目录采用“一个模块一份文档”的方式描述 Soul-agent 内部结构。

---

## 模块索引

| 文档 | 对应源码 | 说明 |
|------|----------|------|
| [应用入口模块](应用入口模块.md) | `main.py`、`cli.py`、`app.py` | 命令入口、CLI 命令、对象组装、交互主循环 |
| [核心模块](核心模块.md) | `core/` | Agent ReAct 循环、对话管理、上下文管理、任务规划 |
| [LLM适配模块](LLM适配模块.md) | `llm/` | LLMClient、OpenAIProvider、LocalProvider、提示词设计 |
| [记忆系统](记忆系统.md) | `memory/` | 短期记忆、长期记忆、向量检索、记忆提取、摘要 |
| [工具系统](工具系统.md) | `tools/` | Tool 基类、注册中心、执行器、6 个内置工具、安全机制 |
| [配置系统](配置系统.md) | `config/` | Pydantic 配置模型、YAML/环境变量加载、默认配置 |
| [UI模块](UI模块.md) | `ui/` | Rich 渲染、Prompt Toolkit 输入、主题系统 |
| [工具与异常模块](工具与异常模块.md) | `utils/` | 日志系统、自定义异常层级 |

---

## 推荐阅读顺序

1. [应用入口模块](应用入口模块.md)：了解程序如何启动、如何组装 Agent。
2. [核心模块](核心模块.md)：理解 Agent 主循环和对话处理。
3. [LLM适配模块](LLM适配模块.md)：理解模型调用和工具调用解析。
4. [工具系统](工具系统.md)：理解 Agent 如何和外部环境交互。
5. [记忆系统](记忆系统.md)：理解长期记忆如何提取、存储和检索。
6. [配置系统](配置系统.md)：理解配置如何影响各模块。
7. [UI模块](UI模块.md)：理解终端展示和输入处理。
8. [工具与异常模块](工具与异常模块.md)：理解基础设施能力。
